# Review checklist
## Product and UX
Purpose, primary task, first-time comprehension, navigation, action priority, feedback, empty/loading/error/success states, destructive-action safety.
## Visual system
Grid, alignment, whitespace rhythm, density, hierarchy, typography roles, color semantics, icon consistency, border/radius/shadow consistency.
## Components and forms
Reuse, variants, states, labels, helper/error text, required/optional clarity, field order, grouping, defaults, validation, submit/cancel placement.
## Responsive/mobile
Safe areas, target size, reachability, keyboard, scrolling, content reflow, truncation, orientation, tablet density.
## Accessibility
Contrast, non-color cues, focus, keyboard order, semantics, labels, reduced motion, zoom/text scaling.
