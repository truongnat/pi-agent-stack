# Screen patterns
## Forms
Prefer persistent labels over placeholder-only labeling. Group fields by user mental model. Put errors near the source and summarize when needed. Avoid disabling submit without explaining unmet requirements. Preserve user input after errors.
## Mobile
Check safe areas, bottom navigation/action reach, touch targets, keyboard obstruction, modal/sheet choice, scroll depth, sticky actions, and back behavior.
## Tablet
Do not simply stretch phone layouts. Use available width for master-detail, supporting panes, or improved information density when useful; constrain reading/form widths.
## Data-dense UI
Optimize scanning and comparison. Keep columns aligned, headers persistent when useful, actions discoverable, selection states unambiguous, and destructive bulk actions guarded. Density controls may be appropriate for expert users.
