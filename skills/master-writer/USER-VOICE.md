# User Voice — quy tắc văn phong đã học, ổn định

File này bắt đầu rỗng. Khi một quy tắc trong `learning-log.md` được user sửa lại theo cùng 1 kiểu ≥ 2 lần, chuyển nó lên đây thành quy tắc chính thức, áp dụng ngay từ đầu ở các lần viết sau — không chờ sửa nữa.

Format mỗi quy tắc:

```
## <tên ngắn quy tắc>
- Luôn/Không bao giờ: <mô tả cụ thể>
- Áp dụng cho: <mode nào / mọi mode>
- Học từ: <ngày, link tới entry trong learning-log.md>
```

(chưa có quy tắc nào)
